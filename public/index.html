What to mint

Execution

One transaction per wallet across N wallets gives N parallel mints on independent nonces — that is what beats a one-per-wallet limit. Several transactions on a single wallet run in nonce order instead.

Mint velocity scan

Samples the sequencer feed for a fixed window and ranks contracts by mint attempts. A serverless function cannot hold the feed open between requests, so this is a snapshot of right now rather than continuous tracking — run npm run serve on a persistent host for that.

Chain & wallets

Mint endpoints are token-authenticated and capped by MAX_MINT_VALUE_ETH. Use burner wallets.
