1Auto-hunt — let it find and buy mints for you

Press start and it runs on its own. Each round it listens to the chain for about 35 seconds to see what is being minted right now, checks each collection against the rules below, and buys the ones that pass — from every wallet that has gas. It keeps going until you stop it.

You do not need to configure anything to start. The settings below already hold sensible defaults chosen to catch fast-selling free mints. Open Adjust the rules only if you want it stricter or looser.

Adjust the rules — what counts as a mint worth buying

Every rule must pass before it buys. Each one rules out a different way of being wrong. Changes apply to the next round and are saved in this browser only. Money limits are not here — the spend cap and price ceiling live on the server so a browser can never widen them.

2Or mint one collection yourself

Only needed if the automatic check cannot work a contract out. Open any successful mint transaction for it on the block explorer, find Input Data, and copy the hex string here.

Setup — access token and deployment

Minting spends real money, so the server refuses to act without a token. Set API_TOKEN in your Vercel environment variables and paste the same value here. It is stored in this browser only and never sent anywhere except your own server.

What do those mean?
apiToken · privateKeys · rpcUrls — whether each is set on the server. All three must be true before it can mint.
network — mainnet spends real ETH; testnet does not.
spendCeilingEth — the hard cap on one run, enforced no matter what the browser asks for.
upstreamTracker — false is normal. Only true if you also run an always-on tracker on a separate machine.
