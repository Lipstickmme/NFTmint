Auto-hunt

Watches live minting on the chain, judges every collection against the rules, and buys the ones that pass — from every wallet that has gas.

Nothing to configure to start. The rules below already hold sensible defaults for catching fast-selling free mints. Each round listens for about 35 seconds, then decides. It keeps going while this tab is open.

Adjust the rules — what counts as worth buying

Every rule must pass before it buys. Changes save in this browser and apply next round. Money limits are not here — the spend cap and price ceiling live on the server so a browser can never widen them.

Mint one yourself

Paste a contract address or any link containing one. It reads the contract — price, supply left, whether the sale is open — and works out the mint call for you.

Check it only reads — it never spends. Mint unlocks once a working call is found.
Advanced — set the mint call by hand

Only needed if the automatic check cannot work a contract out. Open a successful mint for it on the explorer, find Input Data, and paste the hex here.

Setup — access token & deployment

Minting spends real money, so the server refuses to act without a token. Set API_TOKEN in your Vercel environment variables and paste the same value here. It stays in this browser.
